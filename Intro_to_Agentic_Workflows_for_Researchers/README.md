# Claude Code for Scientists and Academics

By Marko Ristić

A guide to Claude Code in the Claude desktop app, written for researchers who do not program. It covers setup, a first session, permission modes, ten research workflows, and how to check the results.

Read it here: [CLAUDE_CODE_FOR_RESEARCHERS.md](CLAUDE_CODE_FOR_RESEARCHERS.md). The figures are in `docs/img/`.

The app changes often. The guide was last checked against the [official documentation](https://code.claude.com/docs) in November 2026.
